# 🌦️ Weather Forecast App

A simple and elegant Flutter weather application that displays real-time weather conditions and forecasts based on the user’s current location. The app uses a clean UI and integrates with a weather API to deliver accurate temperature, humidity, wind, and forecast data.

---

## 🚀 Features

- 📍 **Real-time location detection**
- 
- ☀️ **Current weather** (temperature, humidity, wind speed, condition)
- 📅 **5-day weather forecast**
- 🎨 **Clean and modern Flutter UI**
- 🧭 **Search weather by city**
- 🔄 **Smooth data refresh**
- 📱 Works on both **Android** and **iOS**

---

## 🛠️ Tech Stack

- **Flutter**
- **Dart**
- **OpenWeatherMap / Any Weather API**
- **Geolocator Package**
- **HTTP Package**

## 📲 Getting Started

### 1️⃣ Clone the repository
```bash
git clone https://github.com/yourusername/weather_app.git
cd weather_app
```
---

## 📲 2️⃣ Install dependencies
```bash
flutter pub get
```
---

## 3️⃣ Add your API Key

Edit your .env or config file and insert your weather API key:

const String apiKey = "YOUR_API_KEY_HERE";

---

## 4️⃣ Run the application

```bash
flutter run
```
